Study Buddy: A list stores several values in order under one name. You write it with square brackets:

    scores = [10, 20, 30]

You: Why would I use one instead of separate variables?

Study Buddy: Because it keeps related values together. Without a list you would need a separate
variable for every score:

    score1 = 10
    score2 = 20

That falls apart at thirty scores. With a list you keep one name and loop over it, so the
same code works for three values or three thousand.
